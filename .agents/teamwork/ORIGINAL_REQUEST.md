## Requirements

### R1. Specification: Feature List and User Stories
Create a comprehensive feature list and user stories for a full forms filling automation system (kutomoto) tailored for business, banking, telecom, and other enterprise environments. Document the functional capabilities, workflow engine rules, and visual form designer interactions.

### R2. Visual Form Designer and Workflow Generation
Provide a visual form designer where users can draw form-like boxes, define sequences of fields, and input text. The system must automatically generate an executable action workflow from this visual layout that can be applied to original target forms.

### R3. Step-by-Step Action Workflow Creation and Execution
Allow users to create and execute custom fill flows with sequential action steps (e.g., enter text, press Tab, click specific mouse areas/coordinates, press Enter to submit, and other common form interactions). Support automating form filling and repetitive page actions across open web browser pages and Windows desktop applications.

### R4. Application Implementation and UI
Implement the kutomoto application with a professional, enterprise-grade UI using a portable technology stack suited for Windows OS. Ensure the application is branded as kutomoto with copyrights reserved to 90Studio.
